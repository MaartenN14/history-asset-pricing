## Gecontroleerd en in orde

- Toy-voorbeeld: Var(S₄) = 64/16 = 4; E|S₄| = 24/16 = 1,50; E|S₂| = 1; E|S₃| = (6·1+2·3)/8 = 1,50; E|Sₙ|/√n = 1; 0,707; 0,866; 0,750. Alles gelijk aan de celuitvoer. √(2/π) = 0,798.
- √(8/π) = 1,596 ≈ 1,60; 1,50/1,596 = 0,940, dus "6% onder de limiet" klopt.
- Reflectie: 4/16 + 2/16 = 0,375 (uitvoer 0,375). Order 10 boven 100, σ = 20, 1 jaar: P(S > 110) = 1 − Φ(0,5) = 0,309 → 31%, raakkans 0,617 → 62%.
- Bachelier op het geld: 20/√(2π) = 7,979 → 7,98 (uitvoer 7,9788). De factor 0,3989 ≈ 0,4 klopt.
- Optietabel: het grootste verschil bij 1 maand is 0,0271 ("hooguit drie cent"). Bij 1 jaar en K = 110 is het verschil −0,336 op 3,96/4,29 ("0,34 euro op ongeveer vier euro").
- Bacheliers écart probable: 5·√(2π) = 12,53; ·√30 = 68,6; ·0,6745 = 46,3 → 46 centimes. 33 + 27 = 60 maanden = 1894–1898.
- Bacheliers dichtheid $(1/2\pi a)e^{-x^2/(4\pi a^2)}$ heeft variantie 2πa², dus σ√t = a√(2π). Dat klopt.
- SE autocorrelatie 1/√1200 = 0,029. VR-SE bij T = 1216: 0,0287 / 0,0536 / 0,0848 / 0,1262 → 0,029/0,054/0,085/0,126.
- VR(4) bij alleen ρ₁ = 0,1 is 1,15. AR(1) ρ = 0,1: VR(2) 1,1000, VR(4) 1,1605, limiet 1,2222 (uitvoer).
- T*: (1,96/0,2)² = 96 (1,85 jaar → 1,8), 1537 (29,6 → 30), 9604 (184,7 → 185). De power bij ρ = 0,02 en 23 jaar is 0,107 ("zo goed als onzichtbaar" is verdedigbaar). 2·0,029 = 0,058 ≈ 0,06.
- Nulsimulatie: 0,9998; 0,0281 tegen 0,0287; verwerping 4,3%. 1216/52 = 23,4 jaar ("ruim drieëntwintig").
- Regnault-replicatie: hellingen 0,511 en 0,577 (nagerekend 0,5113 en 0,5766). French E|dev|/√h ligt tussen 0,0373 en 0,0421. √60 = 7,75 ≈ "factor acht".
